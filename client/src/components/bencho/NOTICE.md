# Bencho adaptations

EyeTracker, ToastStack, UploadDropzone Checklist and LiquidToggle are adapted from the Bencho source supplied by the user in this conversation. The supplied components are identified as MIT licensed, with the upstream licence at https://bencho.dev/licence.

The retained comments explain the sphere projection, springs, stack placement, progress display and selection animation. Product-specific adaptations replace the demonstration notification pool, pretend uploads, checklist reset and collapse with controlled real data. Reuse selections never receive a strike-through; deletion previews are explicit and successful API responses drive removal. LiquidToggle uses the supplied single-body, no-filter revision; no upstream images or #liq-goo asset are required. CSS tokens are local aliases of the existing Meta design system.
