# Pollo Tracking UI/UX · Geist V3

本版以用户提供的 Vercel Geist design.md 为全局设计语言，覆盖埋点工作台、正式查询库、权限配置和埋点详情的全部阶段 Tab。

## 视觉基线

- 画布：`#fafafa`；卡片和输入框：`#ffffff`；结构边线：`#ebebeb`。
- 主文字：`#171717`；正文：`#4d4d4d`；辅助文字：`#8f8f8f`；占位文字：`#a1a1a1`。
- 蓝色 `#0070f3` 仅用于链接、焦点和完成状态；红色 `#ee0000` 仅用于破坏性操作；其余页面区域保持黑白灰。
- 功能控件使用 `6px` 方圆角；内容卡片使用 `12px` 圆角；营销式 CTA 才使用全圆角。埋点工作台属于应用界面，按钮和输入框保持紧凑方圆角。
- 默认无阴影，浮层只使用低透明度的 1px/2px 阴影。
- 标题使用 Geist Sans / Inter 600，正文 400，按钮和标签 500；事件 ID、参数 key 和技术字段使用 Geist Mono / JetBrains Mono。

## 事件列表删除交互

事件行默认只展示内容；鼠标悬浮或键盘聚焦时显示右侧删除图标。点击后立即从列表隐藏，并出现深色 snackbar：`事件已删除` + `撤销`。2.6 秒内点击撤销会恢复列表且不调用删除接口；超时后提交删除并清理该事件的设计参数。上线、监控和归档链路中的事件不提供删除入口。

## 验收状态

- 所有 Tab 使用同一套 Geist tokens，不再只修改首页。
- 真实 Base 数据仍然作为页面数据源。
- 事件删除、撤销、阶段锁定和参数表横向滚动均需在本地浏览器验证。
