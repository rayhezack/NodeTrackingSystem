# Pollo Tracking UI/UX · Meta Light V4

本版替换之前的 Geist 深色主操作基线，采用用户提供的 Meta design.md 作为全局视觉语言。

## 核心 tokens

- Canvas：`#ffffff`
- Soft cloud：`#f6f8fa` / `#f4f6f8`
- Hairline：`#e4e7eb`
- Deep ink：`#0a1317`
- Body charcoal：`#4b5157`
- Steel：`#6f7882`
- Cobalt action：`#0866ff`
- Deep cobalt：`#0143b5`
- Critical：`#c62828`
- Success：`#16835b`

## 应用规则

- 页面使用白色卡片和浅云灰工作区，避免大面积黑色背景或黑色主操作造成阅读疲劳。
- 主按钮、筛选激活态、链接和键盘焦点使用钴蓝；按钮、标签和选择控件使用胶囊圆角。
- 16px 卡片圆角、8px 输入圆角、4px spacing base，保持 Meta 的柔和层级并适配高密度数据表。
- 语义色只表达状态：绿色完成/上线、琥珀评审/提醒、红色错误/删除、蓝色进行中/可操作。
- 技术字段使用等宽字体，正文和标题使用 Inter / Optimistic fallback，并开启 `ss01`、`ss02`。

## 页面覆盖

工作台、正式查询库、权限配置、埋点详情的所有阶段 Tab、参数表、弹窗、日期选择器和删除撤销交互均使用同一套 tokens。真实飞书 Base 数据、路由和业务约束保持不变。

## Bencho 交互适配（2026-10-28）

- 查询库的结果区与详情区拆成独立圆角面板；事件行采用圆角选中态。搜索输入移除叠加边框和光晕，保留光标及聚焦底色。
- LiquidToggle 替换端选择：默认 Web，点击、空格/回车或拖动切至 App。紧凑轨道 60×32px、液滴 24px、四边间距 4px；仅释放拖动时更新数据源，取消拖动不切库。
- 日历的年份和月份统一使用应用 Select 弹层；导航层仅箭头可接收点击，避免覆盖中间下拉。年月浏览不更改已选日期。
- EyeTracker 替换左上角字母标识；保留球面投影、眨眼、跟随和点击回应。用户减少动效时静态显示，视口外停止动画。
- ToastStack 接入当前数据负责人的未查看需求，独立于列表筛选和分页。只筛选提需阶段、按需求分组，点击进入 `stage=requirement`。关闭/查看的已读记录保存在当前浏览器并按账号隔离；不跨设备同步，不虚构通知。
- UploadDropzone 使用真实 FileReader 字节进度；2MB / 5 个文件 / 文本格式限制不变，同名和空文件明确拒绝。超过 20,000 字的内容明确标注截取。读取期间禁止生成；点击生成才发送上下文。
- 复用事件及参数使用受控 Checklist，保留跨搜索勾选和独立预览，不加删除线、不自动清空。
- 参数设计使用圆角条目和 Checklist 勾选。删除确认显示划线预览，成功响应后才移除和收拢条目；失败保留数据。需求删除入口使用中性色，最终确认仍保留错误语义色。
- 所有 Bencho tokens 仅在组件根节点映射到 Meta tokens。`framer-motion`、`lucide-react` 已存在，未重复安装。LiquidToggle 采用提供源码中的 NO GOO 单液滴版本，不需要滤镜或外部图片。

验证：客户端/Worker 类型检查、PolloCloud 前端构建通过；30 个相关测试通过。真实 Base 仅做读取、选择和取消预览；未确认任何复用、删除、生成或保存。Impeccable 的 11 条提示均为用户明确指定的弹性动效建议项，保留原效果并支持 reduced-motion；没有阻断项。
