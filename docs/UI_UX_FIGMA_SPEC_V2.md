# Pollo 埋点工作台 V2 · Teamify Figma 视觉提炼

视觉基准来自用户提供的 Teamify Team Dashboard Figma：
<https://www.figma.com/design/6vFSM68JBaZN3vdkef2vcM/Teamify-Team-Dashboard--Community-?node-id=0-1&t=rBbtSyT2U69KaJAA-1>

## 核心结论

采用 Teamify 的浅灰画布、白色圆角应用壳、左侧工作区导航、紫色激活态和多色数据卡片，把埋点流程信息组织成一个轻量的运营仪表盘。

## 视觉规则

- **画布：** 冷浅灰 `#F3F3F6`，应用壳为白色，外层使用约 22px 圆角和柔和阴影。
- **侧边栏：** 宽约 160–180px，近白色底；品牌在顶部，导航分为主工作区和快捷入口；激活项使用浅紫底与紫色图标/文字。
- **主色：** 紫色 `#6D5CE7`，只用于激活导航、主要链接、主按钮和图表重点线。
- **数据卡：** 白色圆角卡片为主，统计摘要允许使用低饱和的桃色、淡紫、浅蓝、薄荷色背景。
- **文字：** 深蓝灰标题 `#2B2940`，辅助文字 `#8D8AA3`；标题使用中等字重，避免厚重黑体。
- **边界：** 细线 `#ECEAF2`；阴影轻量，用于应用壳和卡片层级，不使用深色大阴影。
- **形状：** 应用壳 22px、内容卡 14–18px、导航项 10–12px、头像与图标按钮圆形；按钮可使用胶囊或 10px 圆角，保持 Teamify 的柔和感。

## 页面骨架

### 工作台

1. 应用壳内左侧导航：品牌、Dashboard、Teams/Events、Employees/Owners、Projects/Records、快捷入口、用户信息。
2. 主区顶部：`Good morning, {name}`、短说明、搜索/通知、紫色新增按钮。
3. 第一行：阶段统计卡片，使用 4 个浅色数据卡呈现待处理数量、进行中、已上线和总需求。
4. 第二行：阶段进度图表、待办列表、最近活动/通知。
5. 需求表格放在下方，以白色圆角容器承载筛选、表头、分页。

### 埋点详情页

1. 复用同一应用壳与侧边栏，不再切换为另一套顶部导航。
2. 主区顶部保留面包屑、事件标题、负责人和右侧操作按钮。
3. 流程条放在标题下方，以圆点、连接线和轻色状态呈现提需、设计、评审、开发、验收、上线、归档。
4. 内容区采用三栏白色卡片：左侧阶段导航、中间表单/事件定义、右侧阶段证据与变更记录。
5. 当前阶段使用浅紫背景；完成状态使用薄荷绿；评审提醒使用浅桃色；状态同时显示文字。

### 查询库与权限页

- 查询库保持同一应用壳，事件列表和参数详情使用白色双栏卡片；搜索沿用圆角输入与上下文操作菜单。
- 权限页沿用白色卡片、紫色主按钮、浅灰输入区域，不新增独立色彩体系。

## 组件清单

- `AppShell`：白色圆角壳 + 浅灰画布 + 左侧导航。
- `SidebarNavItem`：默认灰色文字，激活态浅紫底/紫色文字。
- `MetricCard`：白卡或低饱和色卡，数字突出、标签简短。
- `ActivityCard`：头像、事件、时间，单行密度控制。
- `ProcessStepper`：圆点 + 连接线 + 标签，不使用复杂插画。
- `StageEvidenceCard`：右栏摘要，浅色背景块突出业务目标和变更记录。
- `PrimaryButton`：紫色填充；`SecondaryButton`：白底描边；通知、搜索使用图标按钮。

## 禁止项

- 不使用蓝色作为整套界面的主色；蓝色只作为语义状态或链接辅助色。
- 不把详情页改成另一套白蓝后台模板；工作台、详情页、查询库必须共享 AppShell。
- 不使用渐变、大面积装饰插画、深色大屏或锐利直角。
- 不把所有区域做成同一种彩色卡片；彩色只用于统计摘要和语义状态。
